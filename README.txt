SHADOW AI – iPhone web app package

This is an installable web-app project, not a native App Store app.
To install on iPhone, publish these files to an HTTPS host, then open the published site in Safari:
Share -> Add to Home Screen.

The current voice interface is a prototype. Speech recognition depends on iOS Safari support and permissions. Its replies are demo responses until a secure AI backend is connected. Do not put an AI API key in index.html.
